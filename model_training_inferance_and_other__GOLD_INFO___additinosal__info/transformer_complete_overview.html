Decoder: sees only the past → generates future

Each token can only attend to itself and tokens before it (causal mask). Trained to predict the next token. This is what makes ChatGPT-style generation work — the model produces one token at a time, always looking backward, never forward.

Encoder: sees everything → understands deeply

Every token sees every other token in both directions. No mask at all. Trained by masking 15% of tokens randomly and predicting them. Because it sees full context (left AND right), it builds richer understanding — but it can't generate text token-by-token.

Encoder-decoder: understand input → generate output

Two stacks. The encoder reads the full input with bidirectional attention (no mask). The decoder generates output left-to-right with causal mask. A special cross-attention layer lets the decoder look at the encoder's output — "what parts of the input are relevant to the token I'm generating now?"

Attention pattern:
Encoder self-attention: fully open (like BERT)
Decoder self-attention: causal mask (like GPT)
Decoder cross-attention: decoder Q attends to encoder K,V (fully open)

Training task: sequence-to-sequence (input → output)
"translate English to French: The cat sat" → "Le chat s'est assis"

Best for: translation, summarization, structured generation from input
